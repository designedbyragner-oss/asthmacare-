# AsthmaCare — تطبيق الجوال

تطبيق Flutter للنظام الذكي للكشف المبكر عن التغيرات المرتبطة بتفاقم الربو.
**المرجع الحاكم:** `../الوثيقة_الموحدة_AsthmaCare.md` — أي سؤال معماري يُحسم منه.

## التشغيل

```bash
flutter pub get
flutter run                     # على الجوال المتصل (وضع المحاكاة افتراضيًا)
flutter test                    # اختبارات المحرك والحزم
flutter build apk --release     # بناء الإصدار
```

## وضع المحاكاة (D10)

التطبيق يعمل افتراضيًا بمحاكاة موسومة بوضوح «وضع تجريبي — بيانات محاكاة».
السيناريوهات من الإعدادات: مستقرة / نمط تدريجي / ضجيج حركة / انقطاع اتصال / بطارية ضعيفة / تلوث بيئي.

## البنية

```
lib/
├── core/          # الثيم، الأمان (مفتاح DB)، الثوابت
├── data/          # BLE (مجرد + حقيقي + محاكاة)، Drift مشفرة، مستودعات، API خارجي
├── domain/        # محرك الخطر القابل للتفسير + خط الأساس + RiskConfig
├── application/   # مزودات Riverpod، المنسق، الخدمات (إشعارات/تصدير)
└── presentation/  # الشاشات والودجات المشتركة (RTL، Cairo)
```

## قواعد صارمة

- المصطلحات الثلاثة فقط: طبيعي / يستحق الانتباه / نمط يتطلب متابعة
- NO₂/SO₂ موسومة «من مصدر خارجي» دائمًا
- كل تنبيه يُخزَّن مع سببه (§8.7)
- لا اسم مريض في BLE، قاعدة البيانات مشفرة (SQLite3MultipleCiphers)
